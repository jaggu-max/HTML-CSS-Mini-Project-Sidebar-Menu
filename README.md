# 🎨 HTML & CSS Sidebar Navigation

A beginner-friendly web project built while learning **HTML5 and CSS3** through the Apna College web development course.

The project demonstrates how to create a modern sidebar navigation interface using pure HTML and CSS, along with Font Awesome icons and CSS transitions.

---

## 📌 Project Overview

This project is a simple **sidebar navigation UI** created to practice fundamental HTML and CSS concepts.

The sidebar can be opened and closed using a menu button. It includes navigation items, icons, social media links, hover effects, and smooth CSS transitions.

This project was created as part of my journey to learn **Frontend Web Development**.

---

## ✨ Features

- 📂 Sidebar navigation menu
- ☰ Menu open button
- ❌ Close button
- 🎨 Background image
- 🖱️ Hover effects
- ✨ Smooth CSS transitions
- 🔗 Navigation menu items
- 📱 Social media icons
- 🎯 Font Awesome icons
- ☑️ Checkbox-based sidebar control
- 📐 CSS positioning and layout
